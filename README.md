# Comic Money Pro

Comic Money Pro is an Enterprise Edition Personal Finance Management System featuring an intelligent spending analysis, budgeting, and a comic-inspired premium UI. It is designed to be mobile-first and seamlessly convertable into an Android APK via WebView.

## Features

- **Modern Comic Premium UI**: Glassmorphism, floating elements, beautiful gradients, and comic characteristics.
- **Smart Spending Analysis & "Boros" Detector**: AI-based insights to keep your finances healthy.
- **Full PWA Support**: Installable, works offline, app-like experience.
- **Development & Production Ready**: Uses local JSON database for dev and Supabase PostgreSQL for production.
- **Vercel Deployment**: Fully ready for 1-click deployment on Vercel without any code modifications.

## Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JS
- **Backend**: Node.js, Express, REST API
- **Database**: Local JSON (Dev), PostgreSQL/Supabase (Prod)

## Getting Started

1. Clone the repository
2. `npm install`
3. Start the dev server: `npm run dev`

For production deployment:
1. Create a project in Vercel.
2. Link the repository.
3. Add `DATABASE_URL` environment variable for your Supabase instance.
4. Deploy!
